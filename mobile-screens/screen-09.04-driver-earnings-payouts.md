# Screen 09.04: الأرباح والمحفظة المالية والتحويلات (Driver Earnings & Payouts)

## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)

## 🔌 عقود تكامل الخادم (API Endpoints Specification)

### 1. استعلام ملخص المحفظة والأرباح
- **الرابط:** `GET /api/v1/driver/earnings/summary`
- **الصلاحية:** `Bearer Token` (Role: `Driver`)

#### استجابة الخادم النموذجية (`HTTP 200 OK`):
```json
{
  "availableBalanceKwd": 184.500,
  "pendingSettlementKwd": 35.000,
  "monthlyTotalKwd": 420.000,
  "currency": "KWD",
  "breakdown": {
    "baseDeliveryEarningsKwd": 192.000,
    "performanceBonusKwd": 45.000,
    "customerTipsKwd": 12.500
  },
  "bankAccount": {
    "bankName": "National Bank of Kuwait (NBK)",
    "bankNameAr": "بنك الكويت الوطني",
    "iban": "KW82NBOK0000000012345678901234",
    "accountHolderName": "أحمد إبراهيم المري",
    "isVerified": true
  }
}
```

### 2. تقديم طلب سحب بنكي
- **الرابط:** `POST /api/v1/driver/earnings/withdraw`
- **جسم الطلب:**
```json
{
  "amountKwd": 150.000,
  "notes": "تحويل المستحقات الأسبوعية للحساب البنكي"
}
```

#### استجابة الخادم:
```json
{
  "transactionId": "9ba75f64-5717-4562-b3fc-2c963f66afc9",
  "status": "Submitted",
  "amountKwd": 150.000,
  "estimatedTransferDate": "2026-09-24",
  "message": "تم تقديم طلب السحب بنجاح وسيتم إيداعه خلال 24 ساعة عمل."
}
```

## 🛡️ قواعد العمل والأمان المالي (Business Rules & Constraints)
1. **الحد الأدنى للسحب:** 20.000 د.ك لتفادي تكاليف التحويلات المصرفية المتكررة.
2. **التحقق من الآيبان:** لا يمكن طلب تحويل قبل التحقق من مطابقة اسم حامل الحساب مع هوية السائق المسجلة في النظام.
3. **دقة التوقيت والتسوية:** يتم ترحيل أجور التوصيل للرصيد المتاح بمجرد اعتماد المطبخ أو انتهاء 24 ساعة من تسليم الصندوق بدون شكوى أو نزاع مفتوح.

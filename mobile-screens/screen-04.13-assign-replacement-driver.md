# Screen 04.13: تعيين سائق بديل للمهمة المتعثرة (Screen 10.13 - Assign Replacement Driver)

## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)
تُمثّل هذه الشاشة واجهة إنقاذ المهمة التشغيلية (`Emergency Driver Reassignment`) لمسؤول التوصيل (`Dispatcher`) في حال حدوث عطل طارئ، تعطل مركبة، أو عدم استجابة السائق الحالي للمهمة.

تُمكّن الشاشة مسؤول التوصيل من:
1. **معاينة ملخص البلاغ العاجل**: استعراض كود البوكس والمنطقة لتحديد نطاق التدخل الجغرافي.
2. **الاطلاع على كارت السائق الحالي المتعثر**: توثيق هويته وسبب عدم توفره.
3. **استعراض قائمة السائقين البدلاء المرتبين ذكياً**:
   - ترتيب السائقين المتواجدين في **نفس المنطقة الجغرافية** أولاً (`IsInSameArea = true`).
   - حساب المسافة الدقيقة والوقت التقديري للوصول (`DistanceKm` و `EstimatedArrivalMinutes`) بناءً على إحداثيات GPS الحية عبر خوارزمية Haversine.
   - إظهار تقييم السائق وعدد البوكسات المحملة عليه حالياً لتجنب إثقال كاهله.
4. **اختيار وتأكيد الإسناد بنقرة واحدة**: يتم نقل المهمة آلياً في النظام، وتحديث سجل التدقيق الرقابي (`Audit Log`)، وإشعار السائق الجديد.

### 2. تنفيذ تعيين السائق البديل
- **الرابط (Route)**: `POST /api/v1/dispatcher/support/issues/{issueId}/reassign`
- **جسم الطلب (Request Body)**:
```json
{
  "replacementDriverId": "2b3c4d5e-5717-4562-b3fc-2c963f66afa6",
  "notes": "تعطل مركبة السائق الحالي وعدم قدرته على استكمال الرحلة"
}
```
- **الاستجابة المتوقعة (`HTTP 200 OK`)**:

## 📱 إرشادات مطور الموبايل (Flutter / React Native Guidelines)
1. **التعيين الافتراضي**: يُفضل تحديد السائق الأول في القائمة تلقائياً (`Radio Selected by default`) لأنه الأعلى مطابقة جغرافية وأقصر مسافة.
2. **تأكيد العملية (Confirmation Dialog)**: عند النقر على `تأكيد تعيين السائق البديل`، أظهر نافذة تأكيد للمسؤول تحتوي اسم السائق البديل ورقم البوكس.
3. **العودة بعد النجاح**: فور استلام `success: true`، أظهر رسالة نجاح خضراء (`Toast/Snackbar`) ثم عد إلى شاشة الدعم المركزية (`Screen 04.11`) مع تحديث حالتها.

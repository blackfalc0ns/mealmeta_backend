# Screen 09.03: مركز الإشعارات والتنبيهات التشغيلية (Driver Notifications Center)

## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)
تُمثّل هذه الشاشة المركز العصبي للتنبيهات الفورية والتوجيهات الميدانية الواردة للسائق. تجمع الإشعارات المرسلة من المطبخ (جاهزية الشحنة)، ومسؤول التوصيل (إسناد رحلة أو تعديل مسار)، وتنبيهات الحوافز المالية، مع دعم التوجيه المباشر (Deep Linking) للشاشة المعنية فور النقر على الإشعار.

### 1. تصنيف الإشعارات والروابط الذكية (Deep Linking Matrix):
| نوع الإشعار (`type`) | الأيقونة واللون | الإجراء عند النقر (Target Screen) |
|---|---|---|
| `trip-ready-for-pickup` | 🍳 أصفر/برتقالي | الانتقال إلى شاشة قائمة الصناديق للاستلام بالمطبخ (Screen 06.02) |
| `trip-assigned` | 🛵 بنفسجي | الانتقال إلى شاشة تفاصيل الرحلة والخريطة (Screen 05.04) |
| `stop-reassigned` | ⚠️ أحمر | تحديث طابور التوصيل وإظهار رسالة توضيحية بالتعديل |
| `bonus-credited` | 💰 أخضر | الانتقال إلى محفظة الأرباح والسحوبات (Screen 09.04) |
| `document-expiring` | 🪪 رمادي/برتقالي | الانتقال إلى شاشة الوثائق لتحديث المستند (Screen 09.02) |

## 🔌 عقود تكامل الخادم (API Endpoints Specification)

### 1. استعلام قائمة الإشعارات
- **الرابط:** `GET /api/v1/driver/notifications`
- **الصلاحية:** `Bearer Token` (Role: `Driver`)
- **Query Params:** `?pageNumber=1&pageSize=20&filter=All|Pickup|Orders|Finance`

#### استجابة الخادم النموذجية (`HTTP 200 OK`):
```json
{
  "unreadCount": 2,
  "notifications": [
    {
      "id": "8ca75f64-5717-4562-b3fc-2c963f66afa1",
      "type": "trip-ready-for-pickup",
      "title": "الشحنة جاهزة للاستلام بالمطبخ 🍳📦",
      "body": "أنهى مطعم شيلد كيتشن تجهيز وجبات الرحلة TRP-884. يمكنك استلامها الآن.",
      "section": "pickup",
      "deepLink": "/driver/trips/3fa85f64/pickup",
      "subjectId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
      "isRead": false,
      "sentAtUtc": "2026-09-23T06:20:00Z",
      "timeAgoText": "منذ 2 د"
    }
  ]
}
```

### 2. تحديد إشعار كمقروء
- **الرابط:** `POST /api/v1/driver/notifications/{id}/read`

### 3. تحديد الكل كمقروء
- **الرابط:** `POST /api/v1/driver/notifications/read-all`

## 📡 التفاعل اللحظي (SignalR Realtime)
تستقبل الشاشة الإشعارات الحية عبر اتصال الـ `DriverHub`:
* **اسم الحدث:** `notification-received`
* **السلوك:** إصدار نغمة صوتية واهتزاز خفيف، إضافة الكارت أعلى القائمة فوراً، وتحديث شارة العداد غير المقروء في شريط التنقل السفلي.

# Screen 01.03: التحقق من رمز OTP (Verify First-Time OTP)

## 🎯 الغرض من الشاشة
شاشة مستقلة ومنفصلة تماماً مخصصة لإدخال رمز التحقق (OTP) المكون من 6 أرقام المرسل عبر رسالة نصية (SMS) إلى هاتف السائق أو مسؤول التوصيل عند تفعيل حسابه لأول مرة. نجاح التحقق يمنح المستخدم `verificationToken` للانتقال لشاشة تعيين كلمة المرور.

---

## 🎨 عناصر الواجهة والـ Layout (UI Elements)

1. **شريط التنقل العلوي**:
   - زر الرجوع (Back) للعودة لتعديل رقم الهاتف.
2. **العناوين والرسائل**:
   - أيقونة رسالة / درع حماية مع رمز أمان.
   - العنوان الرئيسي: **"رمز التحقق"** / *"Verification Code"*.
   - العنوان الفرعي: **"أدخل الرمز المكون من 6 أرقام المرسل إلى الرقم:"**
   - عرض رقم الهاتف مع زر تعديل سريع: `+966 50 123 4567 ✏️`.
3. **مربعات إدخال الرمز (6-Digit OTP Cells)**:
   - 6 خانات منفصلة تدعم الانتقال التلقائي للخانة التالية، واللصق المباشر (Paste).
   - لوحة المفاتيح الرقمية (Numeric Keypad).
4. **عداد إعادة الإرسال (Resend Countdown)**:
   - عداد تنازلي (مثلاً 60 ثانية): **"إعادة إرسال الرمز خلال 00:59"**.
   - بعد انتهاء العداد يتحول إلى زر نشط: **"إعادة إرسال الرمز"** / *"Resend Code"*.
5. **زر التأكيد (Verify Button)**:
   - زر **"تحقق ومتابعة"** / *"Verify & Continue"*.
   - ينشط تلقائياً بمجرد اكتمال إدخال الـ 6 أرقام.

---

## 🔌 تكامل الباك إند (API Integration)

- **الرابط**: `POST /api/v1/auth/staff/verify-first-time-otp`
- **التوثيق (Auth)**: مفتوح (`Anonymous`)
- **جسم الطلب (Request Body)**:
  ```json
  {
    "phone": "+966501234567",
    "role": "Driver", // أو "DeliveryManager"
    "otpCode": "123456"
  }
  ```

### استجابة النجاح (200 OK):
```json
{
  "verified": true,
  "verificationToken": "CfDJ8IiaSLRQVAJCtZcCGYOjl0AL8geloEPTH98WQfgbB...",
  "phone": "+966501234567",
  "role": "Driver",
  "message": "تم التحقق من الرمز بنجاح. يرجى تعيين كلمة المرور للمتابعة."
}
```

### استجابات الأخطاء المحتملة:
- **400 Bad Request** (`auth.otp_invalid`): الرمز المدخل غير صحيح.
- **400 Bad Request** (`auth.otp_expired`): انتهت صلاحية الرمز (يرجى طلب رمز جديد).

### 2. تأكيد استلام البوكس من المطبخ/المطعم (Pickup & Condition Documentation)
> **ملاحظة تشغيلية هامة:** البوكسات هي **بوكسات وجبات طعام عادية** (ليست حرارية ولا تتطلب إرجاع). يلزم النظام السائق بمسح باركود فاتورة كل بوكس على حدة والتقاط صورة فوتوغرافية واضحة لتوثيق حالته وسلامة تغليفه قبل مغادرة المطعم.

- **الرابط:** `POST /api/v1/driver/orders/{boxId}/pickup`
- **الصلاحية:** `Bearer Token` (`Driver`)
- **Body:**
```json
{
  "barcodeValue": "BX-458722",
  "conditionPhotoStorageKey": "uploads/drivers/delivery/condition_bx458722.jpg",
  "latitude": 29.3375,
  "longitude": 48.0280
}
```
- **قواعد التحقق (Validation Rules):**
  1. `Orders.BarcodeRequired`: لا يمكن الاستلام بدون مسح باركود الفاتورة.
  2. `Orders.ConditionPhotoRequired`: لا يمكن الاستلام بدون تصوير حالة البوكس لتوثيق سلامته ومنع تحميل السائق مسؤولية أي ضرر سابق.
  3. `Orders.BarcodeMismatch`: إذا كان الباركود الممسوح لا يطابق رقم طلب البوكس المخصص للسائق، يُرفض الطلب فوراً لمنع خلط الطلبات.

### 3. تأكيد تسليم البوكس للعميل (Delivery Confirmation & Handover Proof)
> عند وصول السائق لباب العميل، يقوم بمسح باركود فاتورة البوكس للتأكد القطعي من عدم تسليم طلب عميل آخر، مع التقاط صورة إثبات التسليم وحالة البوكس عند التسليم.

- **الرابط:** `POST /api/v1/driver/orders/{boxId}/deliver`
- **الصلاحية:** `Bearer Token` (`Driver`)
- **Body:**
```json
{
  "barcodeValue": "BX-458722",
  "proofPhotoStorageKey": "uploads/drivers/delivery/proof_bx458722.jpg",
  "deliveryOtp": "4812",
  "handoverNotes": "تم التسليم للعميل باليد عند الباب",
  "latitude": 29.3375,
  "longitude": 48.0280
}
```
- **التأثيرات الآلية (Side Effects):**
  * تحديث حالة محطة التوصيل في الرحلة إلى `Delivered`.
  * تسجيل فحص التأكيد في جدول `delivery_confirmation_scans`.
  * زيادة عداد الإنجاز اليومي للسائق تلقائياً (`CompletedOrdersCount += 1`).
  * في حال اكتمال كافة محطات الرحلة، يتم تحويل حالة الرحلة ككل تلقائياً إلى `Completed`.
  * إرسال إشعار لحظي عبر SignalR للمطبخ ولمسؤول التوصيل بتسليم الطلب.

## 📡 التفاعل اللحظي (Real-Time Communication Matrix)
* عند قيام مسؤول التوصيل بإسناد طلب جديد: يستقبل السائق عبر `DriverHub` حدث `box-assigned` مع رنين واهتزاز عاجل.
* عند قيام السائق بتسليم البوكس: يبث الخادم حدث `delivery-completed` لمسؤول التوصيل والمطعم لتحديث العدادات فورياً دون إعادة تحميل الصفحة.

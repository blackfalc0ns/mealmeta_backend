# Screen 03.02: حالة الطلب - مطلوب تعديل البيانات (More Information Needed)

## 🎯 الغرض من الشاشة
المرحلة الثانية (`Stage 2`) من شاشات حالة الطلب؛ تظهر عندما يقوم المطعم أو الإدارة بمراجعة بيانات السائق وطلب تصحيح أو إعادة رفع مستندات محددة (مثل: رخصة غير واضحة أو تاريخ استمارة منتهي)، وتتيح للسائق تعديل المستندات والبيانات وإعادة إرسالها بنقرة واحدة.

---

## 🎨 عناصر الواجهة والـ Layout (مطابقة للموك آب 03.02)

1. **الهيدر العلوي**:
   - شعار MealMate في المنتصف.
   - شارة علوية بلون كهرماني / برتقالي فاتح: **"تعديل البيانات"**.
2. **الرسم التوضيحي المركزي (Illustration)**:
   - لوح مهام (Clipboard) مع علامة تحذير صفراء/كهرمانية ⚠️ وأوراق بلون دافئ تعبر عن الحاجة لإجراء تصحيح.
3. **الرسائل والعناوين**:
   - **العنوان الرئيسي (Title)**: **"مطلوب تعديل البيانات"** / *"Data Modification Required"*.
   - **العنوان الفرعي (Subtitle)**: **"يرجى تعديل البيانات التالية وإعادة إرسال الطلب."** / *"Please update the following information and resubmit your application."*.
4. **صندوق سبب طلب التعديل (Notes Container)**:
   - بطاقة ذات خلفية صفراء باهتة وحد برتقالي ناعم.
   - العنوان: **"سبب طلب التعديل"** (مع أيقونة نقطة برتقالية).
   - عرض نص الملاحظات الواردة من المراجع (`changeRequestNotes`)؛ مثال:
     - • *صورة رخصة القيادة غير واضحة.*
     - • *استمارة المركبة منتهية الصلاحية.*
5. **الأزرار وإجراءات التعديل (Action Buttons)**:
   - **زر الإجراء الرئيسي (Primary Purple Button)**:
     - نص الزر: **"تعديل وإعادة الإرسال"** / *"Update & Resubmit"*.
     - يفتح شاشة رفع المستندات المعدلة أو حقول التعديل المباشرة.
   - **زر الإجراء الثانوي (Secondary Outlined Button)**:
     - نص الزر: **"العودة إلى تسجيل الدخول"** / *"Back to Sign In"*.

---

## 🔌 تكامل الباك إند (API Integration)

### 1. الاستعلام عن الحالة وملاحظات التعديل:
- **الرابط**: `GET /api/v1/auth/staff/driver-registration/status?phone=+966501234567`
- **استجابة الخادم (200 OK)**:
  ```json
  {
    "registrationId": "409286c5-c30f-4f95-b505-38054f0f1285",
    "status": "NeedsChanges",
    "stage": 2,
    "badge": "تعديل البيانات",
    "title": "مطلوب تعديل البيانات",
    "subtitle": "يرجى تعديل البيانات التالية وإعادة إرسال الطلب.",
    "changeRequestNotes": "صورة رخصة القيادة غير واضحة واستمارة المركبة منتهية",
    "canResubmit": true,
    "isApproved": false
  }
  ```

### 2. إعادة إرسال الطلب بعد التعديل:
- **الرابط**: `POST /api/v1/auth/staff/driver-registration/{registrationId}/resubmit`
- **جسم الطلب (Request Body)**:
  ```json
  {
    "drivingLicenseFrontStorageKey": "https://ik.imagekit.io/.../new_lic_front.png",
    "drivingLicenseBackStorageKey": "https://ik.imagekit.io/.../new_lic_back.png",
    "vehicleLicenseExpiry": "2029-12-01T00:00:00Z"
  }
  ```
- **استجابة النجاح (200 OK)**:
  - يُعاد تعيين الحالة فوراً إلى `Submitted` و `stage: 1`.
  - ينتقل التطبيق تلقائياً إلى [الشاشة 03.01: قيد المراجعة](screen-03.01-status-under-review.md).

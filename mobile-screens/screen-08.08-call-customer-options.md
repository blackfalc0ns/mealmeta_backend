# 08.08 - خيارات التواصل البديلة مع العميل (Customer Contact Options)

## 📌 نظرة عامة (Overview)
* **رقم الشاشة وتسميتها:** `08.08 - خيارات التواصل البديلة مع العميل (Customer Contact Options)`
* **الهدف التشغيلي:** توفير بدائل تواصل مرنة للسائق عندما يتعذر الرد على المكالمة الصوتية، حيث تتيح إما إجراء اتصال هاتفي مجاني عبر وسيط، أو إرسال رسالة تذكير فورية SMS/Push Notification لهاتف العميل لتنبيهه بالانتظار عند الباب.
* **المستخدم المستهدف:** السائق الميداني (Driver).

---

## 🎨 عناصر واجهة المستخدم وتجربة الاستخدام (UI / UX Elements)

### 1. نافذة خيارات التواصل (Contact Sheet)
* **العنوان:** **"الاتصال بالعميل"**.
* **سؤال التأكيد:** *"هل تريد الاتصال بالعميل محمد علي الآن؟"*
* **بطاقة العميل:**
  * الصورة الرمزية.
  * اسم العميل: **محمد علي**.

### 2. خيارات الاتصال والتواصل (Contact Channels)
* **الخيار الأول (المكالمة الهاتفية المجانية):**
  * زر عريض بلون بنفسجي/ذهبي:
  * `[ اتصال عبر رقم وسيط (مجاني) 📞 ]` (Call via Proxy - Free).
* **الخيار الثاني (رسالة تنبيه سريعة):**
  * زر ثانوي بإطار أصفر أو أيقونة رسالة 💬:
  * `[ إرسال رسالة تذكير للتواصل 💬 ]` (Send Reminder SMS).
  * ترسل رسالة نموذجية نصها: *"سائق وجبتك من ميل ميت بانتظارك بالأسفل لاستلام الطلب BX-458722 🛵"*.
* **زر الإلغاء:**
  * `إلغاء` للعودة للخريطة.

---

## 🔒 قواعد العمل والتحقق (Business Rules)
1. يتم تقييد إرسال رسائل التذكير بحد أقصى رسالتين لكل طلب منعاً لإزعاج العميل.
2. يتم تسجيل كل محاولة اتصال أو إرسال رسالة في سجل تتبع الطلب لإثبات التزام السائق ومسؤوليته الميدانية في حال تعذر الاستلام.

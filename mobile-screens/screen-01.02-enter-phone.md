# Screen 01.02: إدخال رقم الهاتف وفحص الحساب (Phone Lookup)

## 🎯 الغرض من الشاشة
شاشة البداية الذكية لتسجيل الدخول؛ حيث يقوم المستخدم بإدخال رقم هاتفه المحمول ليقوم الخادم بفحص حالة حسابه وتوجيهه تلقائياً للمسار الصحيح:
- إعداد كلمة المرور لأول مرة (عبر رمز OTP).
- تسجيل الدخول بكلمة المرور (للحسابات الجاهزة).
- توجيه السائق لشاشات متابعة حالة طلبه (إذا كان قيد المراجعة أو مطلوب تعديل بياناته).
- إتاحة زر **"إنشاء حساب جديد"** **للسائق فقط**، وحجبه تماماً عن **مسؤول التوصيل**.

---

## 🎨 عناصر الواجهة والـ Layout (UI Elements)

1. **شريط التنقل العلوي**:
   - زر الرجوع (Back) للعودة إلى شاشة اختيار الدور.
   - شارة الدور الحالي في الزاوية (مثلاً: `سائق` أو `مسؤول توصيل`).
2. **الرسائل التوضيحية**:
   - العنوان: **"تسجيل الدخول"** / *"Sign In"*.
   - الوصف: **"أدخل رقم هاتفك للمتابعة إلى حسابك"** / *"Enter your phone number to continue"*.
3. **حقل إدخال رقم الهاتف (Phone Input Field)**:
   - محدد رمز الدولة (Country Code Picker): الافتراضي `+966` (السعودية) أو `+965` (الكويت) مع علم الدولة.
   - حقل إدخال الرقم مع التحقق الفوري من الصيغة.
4. **زر الإجراء الرئيسي**:
   - زر **"متابعة"** / *"Continue"* (يتحول لحالة تحميل Spinner أثناء الاتصال).
5. **قسم إنشاء حساب جديد (خاص بالسائق فقط 🛑)**:
   - **إذا كان الدور المختار = Driver (سائق)**:
     - يظهر أسفل الشاشة نص: **"ليس لديك حساب سائق؟"** بجانبه رابط: **"إنشاء حساب جديد"** ينقل إلى [الشاشة 02.01: تسجيل سائق جديد](screen-02.01-driver-registration-step1.md).
   - **إذا كان الدور المختار = DeliveryManager (مسؤول توصيل)**:
     - **يُخفى هذا القسم بالكامل**. مسؤول التوصيل يتم إنشاؤه فقط من قِبل المطعم عبر لوحة التحكم ولا يمكنه إنشاء حساب بنفسه.

---

## 🔌 تكامل الباك إند (API Integration)

- **الرابط**: `POST /api/v1/auth/staff/lookup-phone`
- **التوثيق (Auth)**: مفتوح للعامة (`Anonymous`)
- **الترويسات (Headers)**:
  ```http
  Content-Type: application/json
  Accept-Language: ar  # أو en
  ```
- **جسم الطلب (Request Body)**:
  ```json
  {
    "phone": "+966501234567",
    "role": "Driver" // أو "DeliveryManager"
  }
  ```

### استجابات الخادم وسيناريوهات التوجيه:

#### 1. السائق طلبه لا يزال قيد المراجعة أو مطلوب تعديل أو مرفوض (`Stage 1, 2, 3`):
يرجع الخادم `isFirstTimeSetup: false` وكائن `applicationStatus` (دون إرسال OTP):
```json
{
  "exists": true,
  "isFirstTimeSetup": false,
  "role": "Driver",
  "phone": "+966501234567",
  "fullName": "أحمد السائق",
  "restaurantName": "مطعم بروتين لاب",
  "restaurantId": "0a40e4ff-72c7-4754-94e3-50b5f505b730",
  "status": "Submitted",
  "applicationStatus": {
    "registrationId": "409286c5-c30f-4f95-b505-38054f0f1285",
    "stage": 1, // 1 = قيد المراجعة، 2 = مطلوب تعديل، 3 = تم الرفض
    "badge": "قيد المراجعة",
    "title": "حسابك قيد المراجعة",
    "subtitle": "طلب التحاقك قيد المراجعة حالياً من قبل المطعم والإدارة.",
    "notice": "سنقوم بإشعارك عبر إشعار ورسالة نصية فور اكتمال المراجعة.",
    "canResubmit": false,
    "isApproved": false
  }
}
```
➡️ **توجيه التطبيق**: الانتقال مباشرة إلى الشاشة المقابلة (`03.01` إذا كان stage=1، أو `03.02` إذا كان stage=2، أو `03.03` إذا كان stage=3).

#### 2. حساب معتمد وجديد لأول مرة (`isFirstTimeSetup: true`):
يرسل الخادم تلقائياً رمز تحقق OTP عبر رسالة نصية SMS إلى رقم الهاتف:
```json
{
  "exists": true,
  "isFirstTimeSetup": true,
  "role": "Driver", // أو "DeliveryManager"
  "phone": "+966501234567",
  "fullName": "محمد عبدالله",
  "restaurantName": "مطعم بالانس بوكس",
  "restaurantId": "0a40e4ff-72c7-4754-94e3-50b5f505b730",
  "status": "Active",
  "applicationStatus": {
    "stage": 4,
    "isApproved": true
  }
}
```
➡️ **توجيه التطبيق**: الانتقال فوراً إلى [الشاشة 01.03: إدخال رمز التحقق OTP](screen-01.03-verify-otp.md).

#### 3. حساب مفعل وسبق له تعيين كلمة المرور (`isFirstTimeSetup: false`):
```json
{
  "exists": true,
  "isFirstTimeSetup": false,
  "role": "Driver",
  "phone": "+966501234567",
  "fullName": "محمد عبدالله",
  "restaurantName": "مطعم بالانس بوكس",
  "restaurantId": "0a40e4ff-72c7-4754-94e3-50b5f505b730",
  "status": "Active"
}
```
➡️ **توجيه التطبيق**: الانتقال إلى [الشاشة 01.05: تسجيل الدخول بكلمة المرور](screen-01.05-login-password.md).

#### 4. الحساب غير موجود (404 Not Found):
```json
{
  "code": "auth.user_not_found",
  "detail": "المستخدم غير مسجل لدينا."
}
```
- إذا كان الدور = **سائق**: يعرض تنبيهاً ويقترح النقر على "إنشاء حساب جديد".
- إذا كان الدور = **مسؤول توصيل**: يعرض رسالة: *"هذا الرقم غير مسجل كمسؤول توصيل. يرجى التواصل مع إدارة المطعم لإضافتك أولاً."*.

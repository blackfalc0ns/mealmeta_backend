# Screen 06.01: نقطة الاستلام والوصول للمطبخ (En Route to Kitchen / Arrival)

## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)
تُمثّل هذه الشاشة واجهة توجيه السائق إلى مطبخ المطعم لاستلام صناديق الوجبات المخصصة لوردية التوصيل الحالية. توفر الشاشة بيانات المطعم، المسار الجغرافي المباشر، والوقت المتوقع للوصول، وزر تأكيد الحضور الميداني بالمطبخ.

## 🔌 تكامل الخادم (API Integration)

### 1. جلب بيانات نقطة الاستلام
- **الرابط:** `GET /api/v1/driver/pickup/point`
- **الصلاحية:** `Bearer Token` (`Driver`)
- **الاستجابة (`200 OK`):**
```json
{
  "tripId": "7ea85f64-5717-4562-b3fc-2c963f66af10",
  "tripCode": "48-8752",
  "kitchenId": "1fa85f64-5717-4562-b3fc-2c963f66af01",
  "kitchenName": "مطعم MealMate - الكويت",
  "kitchenAddress": "أمام محطة الروضة - العاصمة، الكويت",
  "kitchenLatitude": 29.3375,
  "kitchenLongitude": 48.0280,
  "totalBoxesCount": 8,
  "routeDistanceText": "4.5 كم",
  "estimatedArrivalMinutesText": "10 دقائق",
  "hasArrivedAtKitchen": false,
  "arrivedAtKitchenAtUtc": null
}
```

### 2. تأكيد الوصول للمطبخ
- **الرابط:** `POST /api/v1/driver/pickup/arrive`
- **Body:**
```json
{
  "latitude": 29.3375,
  "longitude": 48.0280
}
```
- **التأثير:** يبث إشعار SignalR لحظي `driver-arrived-at-kitchen` للوحة المطبخ ولوحة مسؤول التوصيل، وينقل السائق تلقائياً إلى الشاشة `06.02`.

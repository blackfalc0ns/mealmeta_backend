# Screen 01.06: نسيت كلمة المرور (Forgot Password - Phone Input)

## 🎯 الغرض من الشاشة
تتيح للسائق أو مسؤول التوصيل الذي نسي كلمة المرور الخاصة به طلب رمز تحقق OTP إلى رقم هاتفه المسجل لإعادة تعيين كلمة مرور جديدة.

---

## 🎨 عناصر الواجهة والـ Layout (UI Elements)

1. **الهيدر العلوي**:
   - زر الرجوع (Back) للعودة لشاشة تسجيل الدخول بكلمة المرور.
2. **الرسائل التوضيحية**:
   - أيقونة أمان واستعادة الحساب.
   - العنوان: **"نسيت كلمة المرور؟"** / *"Forgot Password?"*.
   - الوصف: **"أدخل رقم هاتفك المسجل وسنرسل لك رمز تحقق لإعادة تعيين كلمة المرور الخاصة بك"**.
3. **حقل إدخال رقم الهاتف**:
   - يتم تعبئته تلقائياً برقم الهاتف الذي كان المستخدم يحاول الدخول به.
   - إمكانية التعديل مع محدد كود الدولة.
4. **زر الإجراء**:
   - زر **"إرسال رمز التحقق"** / *"Send Verification Code"*.

---

## 🔌 تكامل الباك إند (API Integration)

- **الرابط**: `POST /api/v1/auth/staff/forgot-password`
- **التوثيق (Auth)**: مفتوح (`Anonymous`)
- **جسم الطلب (Request Body)**:
  ```json
  {
    "phone": "+966501234567",
    "role": "Driver" // أو "DeliveryManager"
  }
  ```

### استجابة النجاح (200 OK):
```json
{
  "success": true,
  "message": "تم إرسال رمز استعادة كلمة المرور إلى هاتفك بنجاح."
}
```

### الأخطاء المحتملة:
- **404 Not Found** (`auth.user_not_found`): رقم الهاتف غير مسجل في النظام.

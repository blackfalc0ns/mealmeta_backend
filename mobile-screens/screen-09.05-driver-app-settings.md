# Screen 09.05: إعدادات التطبيق والتفضيلات والمزامنة (Driver App Settings & Preferences)

## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)
تُمكّن هذه الشاشة السائق من تخصيص تجربة استخدام التطبيق أثناء القيادة، مثل اختيار تطبيق الخرائط والملاحة المفضل، وتفعيل التنبيهات الصوتية الحركية، وضبط خيارات حفظ البيانات والمزامنة غير المتصلة (Offline Queue)، بالإضافة لإدارة الأمان (البصمة وكلمة المرور) وتسجيل الخروج الآمن.

## 🔌 عقود تكامل الخادم (API Endpoints Specification)

### 1. استعلام تفضيلات السائق
- **الرابط:** `GET /api/v1/driver/settings`
- **الصلاحية:** `Bearer Token` (Role: `Driver`)

#### استجابة الخادم:
```json
{
  "preferredLanguage": "ar",
  "preferredNavigationApp": "GoogleMaps",
  "autoLaunchNavigation": true,
  "soundAlertsEnabled": true,
  "vibrationEnabled": true,
  "biometricLoginEnabled": true,
  "offlineSync": {
    "autoSyncOnReconnect": true,
    "pendingSyncItemsCount": 0,
    "lastSyncedAtUtc": "2026-09-23T06:25:00Z"
  }
}
```

### 2. تحديث التفضيلات
- **الرابط:** `PUT /api/v1/driver/settings`
- **جسم الطلب:**
```json
{
  "preferredLanguage": "ar",
  "preferredNavigationApp": "GoogleMaps",
  "autoLaunchNavigation": true,
  "soundAlertsEnabled": true
}
```

### 3. مزامنة طابور العمليات غير المتصلة فورياً (Manual Trigger)
- **الرابط:** `POST /api/v1/driver/sync/offline-queue`
- يتم استدعاؤه لمعالجة كافة عمليات المسح والتسليم المخزنة محلياً عند عودة الشبكة.

## 🛡️ قواعد الأمان ومنع التعارض التشغيلي (Safety Constraints)
* **منع تسجيل الخروج أثناء وجود وردية نشطة:** إذا حاول السائق تسجيل الخروج بينما الوردية `Active` أو توجد صناديق بحوزته لم تُسلّم بعد، تمنع الشاشة العملية وتظهر تنبيهاً يلزمه بإنهاء الوردية (Screen 05.03) أو إعادة الصناديق للمطبخ أولاً.

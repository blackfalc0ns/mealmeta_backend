# Screen 04.05: قائمة أسطول السائقين والتحكم في الإتاحة (Dispatcher Drivers List & Fleet Management)

## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)
تُمثّل هذه الشاشة واجهة الإشراف والتحكم التشغيلي الكامل في أسطول السائقين التابع للمطعم من قِبل مسؤول التوصيل (`Dispatcher / Delivery Manager`).
تُتيح الشاشة لمسؤول التوصيل:
1. **المراقبة اللحظية للطاقة الاستيعابية للأسطول** عبر 4 عدادات حية علوية (الإجمالي، المتاحين، الخارجين للتوصيل، وغير المتاحين).
2. **البحث السريع ومتعدد المعايير** في الاسم العربي والإنجليزي، رقم الهاتف، كود السائق، أو رقم لوحة المركبة.
3. **التصفية بحسب الحالة التشغيلية** (`All`, `Available`, `InDelivery`, `Unavailable`) والترتيب حسب الاسم، التقييم، الأحدث، أو الحالة.
4. **التحكم المباشر في إتاحة السائق (`Availability Toggle`)** بنقرة واحدة لتفعيل أو إيقاف استقبال السائق لمهام جديدة، مع الحفاظ الآمن على استمرار الرحلات النشطة إن وجدت.
5. **الانتقال السريع إلى شاشة التفاصيل الكاملة (`Screen 04.07`)** عند النقر على أي كارت سائق.
6. **الاتصال الفوري بالسائق** عبر تطبيق الهاتف الافتراضي عبر رابط `tel:`.
7. **التحديث الفوري عبر SignalR** عند تغيير توفر السائق أو حالته التشغيلية دون الحاجة لإعادة تحميل الصفحة.

## ⚙️ قواعد الحالات التشغيلية والتبديل (Operational State & Priority)

1. **أولوية الحالة التشغيلية ثلاثية المستويات (3-Tier Priority)**:
   - **`InDelivery` (أزرق)**: السائق لديه مهمة أو رحلة نشطة (`Assigned` أو `InProgress`) وتتضمن توقفات قيد الاستلام أو التوصيل (`PickedUp` أو `Pending`).
   - **`Available` (أخضر)**: لا توجد رحلة نشطة، و `isAvailable == true`.
   - **`Unavailable` (رمادي)**: لا توجد رحلة نشطة، و `isAvailable == false`.

2. **سلوك تبديل الإتاحة (Availability Toggle Switch)**:
   - تبديل الإتاحة إلى `false` **لا يوقف ولا يلغي** رحلة السائق الحالية إن كان خارجاً للتوصيل.
   - إذا كان السائق في حالة `InDelivery` وتم إيقاف إتاحته:
     - تظل حالته التشغيلية `InDelivery` حتى إكمال كافة نقاط التوصيل.
     - بعد إنهاء الرحلة ينتقل تلقائياً إلى حالة `Unavailable`.
     - لا يظهر السائق ضمن المرشحين المؤهلين لإسناد بوكسات جديدة.
   - عند النقر على السويتش:
     - إظهار مؤشر تحميل صغير داخل السويتش (Optimistic or Loading state).
     - استدعاء `PATCH /api/v1/dispatcher/drivers/{id}/availability`.
     - تسجيل سبب التغيير الاختياري إن أراد المسؤول إدخاله.

## 🔌 عقود تكامل الـ API (API Contracts)

### 1. جلب قائمة السائقين مع العدادات والترقيم (Get Drivers List)

- **الرابط**: `GET /api/v1/dispatcher/drivers`
- **المعاملات (Query Parameters)**:
  - `search` (اختياري): نص البحث في الاسم أو الهاتف أو الكود أو اللوحة.
  - `status` (اختياري - افتراضي `All`): `All` | `Available` | `InDelivery` | `Unavailable`.
  - `sortBy` (اختياري - افتراضي `Name`): `Name` | `RatingDesc` | `Newest` | `Status`.
  - `pageNumber` (اختياري - افتراضي `1`): رقم الصفحة.
  - `pageSize` (اختياري - افتراضي `15`): عدد السائقين في كل صفحة.
- **الترويسات (Headers)**:
  ```http
  Authorization: Bearer <JWT_TOKEN>
  Accept-Language: ar  # أو en
  ```

- **استجابة الخادم الناجحة (200 OK)**:

### 2. تبديل إتاحة السائق (Toggle Driver Availability)

- **الرابط**: `PATCH /api/v1/dispatcher/drivers/{driverId}/availability`
- **جسم الطلب (Request Body)**:
```json
{
  "isAvailable": false,
  "reason": "استراحة غداء مجدولة"
}
```

- **استجابة الخادم الناجحة (200 OK)**:
```json
{
  "driverId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "isAvailable": false,
  "operationalStatus": "Unavailable",
  "hasActiveAssignments": false,
  "updatedAtUtc": "2026-09-27T11:45:00Z"
}
```

## 📡 التحديثات الفورية (SignalR Real-time Events)

- **اسم الهاب**: `/hubs/dispatcher-hub`
- **الانضمام للمجموعة**: ينضم التطبيق تلقائياً لمجموعة المطعم: `restaurant:{restaurantId}:dispatcher`
- **الحدث المستمع له**: `driver-availability-updated`
- **الحمولة (Payload)**:
```json
{
  "driverId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "isAvailable": false,
  "operationalStatus": "Unavailable",
  "hasActiveAssignments": false,
  "updatedAtUtc": "2026-09-27T11:45:00Z"
}
```
- **سلوك الواجهة عند استلام الحدث**:
  1. تحديث سويتش التوفر `isAvailable` للكارت المقابل.
  2. تحديث شارة الحالة `operationalStatus` ولونها.
  3. إعادة حساب أو تعديل العدادات العلوية فوراً دون إعادة طلب القائمة.

## 🛡️ معالجة الأخطاء وحالات الحافة (Error Handling & Edge Cases)

| رمز الخطأ | الحالة | السبب | التصرف في تطبيق الموبايل |
|---|---|---|---|
| `401 Unauthorized` | غير مسجل | انتهاء الجلسة أو عدم إرسال التوكن | تحويل المستخدم لشاشة الدخول `01.05` |
| `403 Forbidden` | ممنوع | لا يمتلك صلاحية `delivery.dispatch.manage` أو `delivery.drivers.manage` | إظهار تنبيه بصري يوضح عدم كفاية الصلاحيات |
| `404 Not Found` | غير موجود | السائق غير موجود أو تابع لمطعم آخر | إظهار "السائق غير موجود" وتحديث القائمة |
| **سائق بدون هاتف** | `phoneNumber: null` | لم يُدخل السائق هاتفه بعد | تعطيل زر الاتصال أو إظهار "الهاتف غير مسجل" |
| **سائق بدون تقييم** | `rating: null` | لم يقم أي عميل بتقييمه بعد | إظهار شارة "جديد ⭐" بدلاً من رقم صفر |
| **قائمة فارغة** | `items: []` | لا يوجد سائقون بالمطعم | إظهار شاشة الحالة الفارغة: "لا يوجد سائقون مسجلون حالياً" |

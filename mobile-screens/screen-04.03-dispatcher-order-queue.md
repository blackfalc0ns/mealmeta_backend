# Screen 04.03: إدارة الطلبات وطابور البوكسات في انتظار الإسناد (Dispatcher Order Queue & Box Assignment)

## 🎯 الغرض من الشاشة ونظرة عامة
تُمكّن هذه الشاشة مسؤول التوصيل / المرسل (`Dispatcher / Delivery Manager`) من:
1. تتبع طابور بوكسات الوجبات الجاهزة بانتظار الإسناد في الوقت الفعلي.
2. فلترة البوكسات حسب الحالة التشغيلية (`الكل`, `بانتظار الإسناد`, `تم الإسناد`, `قيد التوصيل`, `مشاكل`).
3. الاستفادة من **محرك الترشيح الذكي للسائقين (`Smart Dispatch Recommendation Engine`)** الذي يوصي بالسائق الأقرب أو الأقل ضغطاً لكل بوكس.
4. تنفيذ الإسناد السريع للبوكسات بنقرة زر مع استعراض قائمة السائقين المرشحين.
5. استعراض تفاصيل البوكس (المنطقة، عدد الوجبات، نافذة التسليم، والمسافة بالكيلومتر).

## 🎨 التحليل البصري والتخطيطي (UI/UX Breakdown & Components)

- العنوان الرئيسي: **الطلبات**
- العنوان الفرعي: **طابور البوكسات في انتظار الإسناد**

### 2. شريط العدادات الحيوية الـ 4
- 🕒 **بانتظار الإسناد**: `23`
- 🟢 **تم الإسناد**: `37`
- 🔵 **قيد التوصيل**: `58`
- 🔴 **مشاكل**: `2`

### 3. شريط فلاتر الحالات الأفقية (Filter Chips)
- زر `الكل 23` (بنفسجي نشط).
- زر `بانتظار الإسناد 23` (نقطة برتقالية).
- زر `تم الإسناد 37` (نقطة خضراء).
- زر `قيد التوصيل 58` (نقطة زرقاء).
- زر `مشاكل 2` (نقطة حمراء).

### 4. بطاقات البوكسات (Box Cards)
تحتوي كل بطاقة على:
- كود البوكس المميز: مثل `#BX-1256` مع أيقونة 📦.
- شارة الأولوية: `جديد` (أخضر)، `عاجل 📢` (أحمر)، `أولوية عالية ⭐` (برتقالي)، `عادي` (رمادي).
- المنطقة الجغرافية: مثل `منطقة السالمية`، `منطقة حولي`، `منطقة الفحيحيل`.
- عدد الوجبات: مثل `8 وجبات`، `5 وجبات`، `4 وجبات`.
- نافذة التسليم: `09:30-10:30 ص`.
- المسافة التقديرية: `6.2 كم`.
- التوصية الذكية بالسائق:
  - `اقتراح: أحمد الأقرب 👤` (بناءً على القرب الجغرافي).
  - `الأقل ضغطاً: محمد 👤` (بناءً على توازن الأحمال).
- الأزرار:
  - زر عريض بنفسجي: `إسناد 👤` (يفتح نافذة اختيار السائق).
  - زر ثانوي: `التفاصيل`.

### 3. تأكيد إسناد البوكس لسائق
- **الرابط**: `POST /api/v1/dispatcher/orders/{boxId}/assign`
- **الطلب (Request Body)**:
```json
{
  "driverId": "11111111-1111-1111-1111-111111111111",
  "notes": "إسناد سريع للوردية الصباحية"
}
```
- **الاستجابة (200 OK)**:
```json
{
  "boxId": "a1111111-1111-1111-1111-111111111111",
  "boxCode": "#BX-1256",
  "driverId": "11111111-1111-1111-1111-111111111111",
  "driverName": "أحمد السعيد",
  "assignedAtUtc": "2026-09-21T07:30:00Z",
  "message": "تم إسناد البوكس للسائق بنجاح"
}
```
- **حدث البث المباشر (SignalR Event)**:
  - الحدث: `box-assigned`
  - المجموعة: `restaurant:{restaurantId}:dispatcher`

# Screen 03.03: حالة الطلب - تم رفض الطلب (Application Rejected)

## 🎯 الغرض من الشاشة
المرحلة الثالثة (`Stage 3`) من شاشات حالة الطلب؛ تظهر عندما يتقرر عدم قبول طلب السائق من قِبل المطعم أو الإدارة. توضح أسباب الرفض بوضوح تام، وتمنح السائق فرصة لإعادة التقديم وتعديل المستندات المخالفة.

---

## 🎨 عناصر الواجهة والـ Layout (مطابقة للموك آب 03.03)

1. **الهيدر العلوي**:
   - شعار MealMate في المنتصف.
   - شارة علوية بلون أحمر فاتح: **"رفض الطلب"** / *"Application Rejected"*.
2. **الرسم التوضيحي المركزي (Illustration)**:
   - لوح مهام (Clipboard) مع دائرة حمراء بداخلها علامة إغلاق حمراء `✖` وبتلات بلون أحمر هادئ.
3. **العناوين والرسائل**:
   - **العنوان الرئيسي (Title)**: **"تم رفض الطلب"** / *"Application Rejected"*.
   - **العنوان الفرعي (Subtitle)**: **"عذراً، لم يتم قبول طلبك الحالي. يرجى مراجعة سبب الرفض أدناه. يمكنك تعديل البيانات وإعادة التقديم."** / *"Sorry, your current application was not accepted. Please review the reason below. You can update your data and reapply."*.
4. **صندوق سبب الرفض (Rejection Reasons Container)**:
   - بطاقة ذات خلفية وردية فاتحة (Light Pink) وحدود ناعمة.
   - العنوان: **"سبب الرفض"** بنص أحمر غامق.
   - نقاط التوضيح المستلمة من الخادم (`rejectionReason`)؛ مثال:
     - • *الرقم الصحي غير مطابق للبيانات.*
     - • *تاريخ صلاحية رخصة القيادة منتهي.*
     - • *صورة استمارة المركبة غير واضحة.*
5. **الأزرار وإجراءات إعادة التقديم (Action Buttons)**:
   - **زر الإجراء الرئيسي (Primary Purple Button)**:
     - نص الزر: **"إعادة التقديم"** / *"Reapply"*.
     - يفتح معالج تسجيل السائق محملاً ببياناته السابقة ليقوم بتعديل الحقول المرفوضة وإعادة الرفع.
   - **زر الإجراء الثانوي (Secondary Outlined Button)**:
     - نص الزر: **"العودة إلى تسجيل الدخول"** / *"Back to Sign In"*.

- **الرابط**: `GET /api/v1/auth/staff/driver-registration/status?phone=+966501234567`
- **استجابة الخادم (200 OK)**:
  ```json

    "status": "Rejected",

    "badge": "تم رفض الطلب",
    "title": "تم رفض الطلب",

    "rejectionReason": "الرقم الصحي غير مطابق للبيانات، وصورة استمارة المركبة غير واضحة",

  ```

## 🔄 السلوك والتنقل (Navigation)
- عند النقر على **"إعادة التقديم"**:
  - يتم تحميل بيانات السائق الحالية ونقله لمعالج التسجيل أو استدعاء `POST /resubmit`.
  - فور إرسال التحديث، يعود الطلب إلى [الشاشة 03.01: قيد المراجعة](screen-03.01-status-under-review.md).

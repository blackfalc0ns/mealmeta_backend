# 08.07 - الاتصال بالعميل برقم مقنع لحماية الخصوصية (Masked Customer Call)

## 📌 نظرة عامة (Overview)
* **رقم الشاشة وتسميتها:** `08.07 - الاتصال بالعميل برقم مقنع لحماية الخصوصية (Masked Customer Call)`
* **الهدف التشغيلي:** توفير أعلى معايير الأمان وخصوصية البيانات للعملاء والسائقين من خلال إجراء المكالمات عبر خط هاتف وسيط مشفر (Virtual Proxy / VoIP Masking) دون إظهار رقم الهاتف الشخصي لأي من الطرفين.
* **المستخدم المستهدف:** السائق الميداني (Driver).

---

## 🎨 عناصر واجهة المستخدم وتجربة الاستخدام (UI / UX Elements)

### 1. طبقة الخلفية والنافذة المنبثقة (Modal Sheet)
* نافذة منبثقة سفلية (Bottom Sheet) مصممة بعناية لسرعة التفاعل.

### 2. شارة الأمان والخصوصية (Privacy Shield Badge)
* أيقونة درع الأمان 🛡️ بلون برتقالي/ذهبي:
  * نص الشارة: *"حماية الخصوصية: يتم الاتصال عبر رقم وسيط آمن لحماية بيانات العميل والسائق."*

### 3. بيانات العميل المعروضة
* الصورة الرمزية للعميل.
* اسم العميل: **محمد علي**.
* رقم هاتف مقنع يظهر بصيغة رمزية: `+965 •••• 5432` لضمان عدم تسريب بيانات الاتصال الشخصية.

### 4. أزرار الإجراءات (Action Buttons)
* **الزر الرئيسي:**
  * `[ اتصال الآن 📞 ]` (Call via Masked Proxy).
  * يربط السائق ببدالة التحويل الآلية للمنصة برقم مجاني، وتتولى البدالة توجيه الاتصال مباشرة للعميل.
* **زر الإلغاء:**
  * `إلغاء` للعودة.

---

## 🔌 تكامل الواجهة الخلفية (Backend API Integration)

### جلب بيانات الرقم الوسيط
```http
GET /api/v1/driver/orders/{boxId}/call-proxy HTTP/1.1
Authorization: Bearer <driver_token>
```

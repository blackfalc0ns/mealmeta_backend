# Screen 04.11: مركز الدعم وإدارة المشكلات التشغيلية (Screen 10.11 - Support & Issues)

## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)
تُمثّل هذه الشاشة الواجهة الرئيسية لمركز الدعم وإدارة المشكلات التشغيلية في الميدان لمسؤول التوصيل (`Dispatcher`)، وتتيح له:
1. **المراقبة الفورية للحالات الطارئة**: رصد الشكاوى، البوكسات المفقودة، تلف الوجبات، وتأخر السائقين في الوقت الفعلي.
2. **مؤشرات الحالات الكلية (KPI Counters)**: 3 عدادات بارزة وسريعة أعلى الشاشة (`تم الحل`، `جاري الحل`، `مفتوحة`).
3. **التصفية السريعة حسب المناطق الجغرافية (Area Chips)**: فلترة المشكلات وفق مناطق ومحافظات الكويت (`السالمية`، `حولي`، `الفروانية`، `العاصمة`، أو `الكل`).
4. **تبويبات حالة المعالجة (Status Tabs)**: التبديل الفوري بين البلاغات (`مفتوحة` Open، `جاري الحل` In Progress، `تم الحل` Resolved).
5. **البحث المباشر**: البحث الفوري بكود البوكس أو اسم السائق أو كوده.
6. **كروت البلاغات الملونة الغنية**: عرض تفاصيل المشكلة، كود البوكس، المنطقة، درجة الأولوية، واسم السائق مع بيانات مركبته الفعلية (`تويوتا كامري • أبيض`).

## 🔌 عقد تكامل الخادم (API Endpoint Specification)

### 1. استعلام قائمة المشكلات والعدادات والفلاتر
- **الرابط (Route)**: `GET /api/v1/dispatcher/support/issues`
- **الصلاحية (Authorization)**: `Bearer Token` (دور مسؤول التوصيل `DeliveryManager` أو `Admin`)
- **Query Parameters**:
  | المعامل | النوع | إلزامي؟ | الوصف |
  | :--- | :--- | :--- | :--- |
  | `area` | `string` | لا | فلترة حسب المنطقة مثل `السالمية` أو `حولي` (إذا ترك فارغاً يعيد الكل) |
  | `status` | `string` | لا | حالة المشكلة (`Open`، `InProgress`، `Resolved`) |
  | `search` | `string` | لا | نص البحث للبحث برقم البوكس أو اسم السائق أو كوده |

## 📱 إرشادات مطور الموبايل (Flutter / React Native Guidelines)
1. **الربط مع شاشة التفاصيل**: عند النقر على أي كارت، انتقل إلى `Screen 04.12` مع تمرير معرف المشكلة `issue.id`.
2. **التحديث الحي**: يُنصح بإعادة استدعاء الـ Endpoint كل 30 ثانية لتحديث العدادات والمشكلات الطارئة أو الاستماع لحدث SignalR المركزي.
3. **تلوين الشارات (Badges)**: استخدام الحقل `issueCategoryColor` و `priorityColor` لتلوين الشارات ديناميكياً بما يطابق الهوية البصرية.

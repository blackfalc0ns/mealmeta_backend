# Screen 06.03: ماسح الباركود ورمز QR (QR & Barcode Scanner)

## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)
تُمثّل هذه الشاشة أداة الفحص الضوئي لقراءة الباركود أو رمز QR الملصق على فاتورة صندوق الوجبة. تُتيح الشاشة الفحص السريع عبر الكاميرا مع دعم تشغيل الفلاش، وتوفر خياراً بديلاً للإدخال اليدوي لأرقام الرمز عند تعذر المسح الضوئي.

## 🔌 تكامل الخادم (API Integration)

- **الرابط:** `POST /api/v1/driver/pickup/validate-barcode`
- **Body:**
```json
{
  "barcodeValue": "480K-1234"
}
```

### 1. حالة الرمز المطابق بنجاح (`HTTP 200 OK`):
يتم الانتقال مباشرة إلى الشاشة `06.04` لتصوير البوكس وتوثيق حالته.
```json
{
  "isValid": true,
  "boxId": "2fa85f64-5717-4562-b3fc-2c963f66af11",
  "boxCode": "480K-1234",
  "customerName": "محمد علي",
  "deliveryZone": "حي الروضة",
  "mealsCount": 3,
  "scanStatus": "PendingScan",
  "message": "تم التحقق من البوكس بنجاح. يرجى التقاط صورة لحالته لتوثيق الاستلام.",
  "belongsToThisDriver": true,
  "assignedDriverId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "assignedDriverName": "أحمد إبراهيم"
}
```

### 2. حالات الأخطاء المرتبطة:
* إذا كان الرمز غير مسجل أو تالف ➔ الانتقال للشاشة `06.12` (رمز غير صالح).
* إذا كان البوكس مسنداً لسائق آخر ➔ الانتقال للشاشة `06.13` (هذا الرمز لا يخصك).
* إذا لم يتمكن المستشعر من القراءة لـ 15 ثانية ➔ الانتقال للشاشة `06.11` (انتهت مهلة المسح).

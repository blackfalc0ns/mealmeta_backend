## 🎯 الغرض من الشاشة ونظرة عامة (Overview & Purpose)
تُمثّل هذه الشاشة أداة الفحص الضوئي لقراءة الباركود أو رمز QR الملصق على فاتورة صندوق الوجبة. تُتيح الشاشة الفحص السريع عبر الكاميرا مع دعم تشغيل الفلاش، وتوفر خياراً بديلاً للإدخال اليدوي لأرقام الرمز عند تعذر المسح الضوئي.

## 🔌 تكامل الخادم (API Integration)

- **الرابط:** `POST /api/v1/driver/pickup/validate-barcode`
- **الصلاحية:** `Bearer Token` (`Driver`) — مستخرج تلقائياً من الجلسة الموثقة، بدون تمرير `driverId`.
- **Body:**
```json
{
  "barcodeValue": "480K-1234",
  "isManualEntry": false
}
```

### 1. حالة الرمز المطابق بنجاح (`HTTP 200 OK`):
يُصدر الخادم رمز تحقق أمني مؤقت (`validationToken`) صالح لمدة 5 دقائق ومربوط بـ SHA-256، ويتم الانتقال مباشرة إلى الشاشة `06.04` لتصوير البوكس وربطه برمز التحقق.
```json
{
  "isValid": true,
  "validationToken": "c3f87a9b0e1d4c2a...",
  "expiresAtUtc": "2026-09-27T08:05:00Z",
  "box": {
    "boxId": "2fa85f64-5717-4562-b3fc-2c963f66af11",
    "boxCode": "480K-1234",
    "customerName": "محمد علي",
    "deliveryZone": "حي الروضة",
    "mealsCount": 3
  },
  "scanStatus": "BarcodeValidated",
  "nextAction": "CaptureConditionPhoto"
}
```

### 2. حالات الأخطاء البرمجية المعتمدة (Error Codes):
| كود الخطأ | السبب | التوجيه في التطبيق |
| :--- | :--- | :--- |
| `BARCODE_REQUIRED` | لم يتم إرسال قيمة الباركود أو فارغة | إشعار بضرورة مسح الرمز |
| `BOX_NOT_IN_ACTIVE_TRIP` | السائق لا يملك رحلة توصيل نشطة | الانتقال لشاشة الانتظار `06.01` |
| `BARCODE_NOT_FOUND` | الرمز غير موجود بالنظام نهائياً أو غير مقروء | الانتقال للشاشة `06.12` (رمز غير صالح) |
| `BOX_NOT_ASSIGNED_TO_DRIVER` | الصندوق مسند لسائق آخر في رحلة مختلفة | الانتقال للشاشة `06.13` (هذا الرمز لا يخصك) |
| `BOX_ALREADY_PICKED_UP` | تم استلام الصندوق وتأكيده مسبقاً | إشعار بأن الصندوق مستلم بالفعل |

> [!IMPORTANT]
> رمز التحقق `validationToken` صالح لمدة **5 دقائق فقط**. إذا انتهت مهلته أثناء التقاط الصورة يجب إعادة مسح الباركود للحصول على رمز جديد قبل التأكيد.

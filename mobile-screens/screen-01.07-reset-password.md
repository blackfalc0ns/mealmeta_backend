# Screen 01.07: إعادة تعيين كلمة المرور (Reset Password)

## 🎯 الغرض من الشاشة
شاشة إدخال رمز التحقق (OTP) المستلم لاستعادة الحساب مع تعيين كلمة المرور الجديدة وتأكيدها في خطوة واحدة آمنة وسلسة.

---

## 🎨 عناصر الواجهة والـ Layout (UI Elements)

1. **الهيدر العلوي**:
   - زر الرجوع (Back) لشاشة طلب الاستعادة.
2. **الرسائل والعناوين**:
   - العنوان: **"إعادة تعيين كلمة المرور"** / *"Reset Password"*.
   - العنوان الفرعي: **"أدخل رمز التحقق المرسل لهاتفك ثم اكتب كلمة المرور الجديدة"**.
3. **مربعات إدخال الرمز (6-Digit OTP)**:
   - 6 خانات منفصلة تدعم اللصق المباشر.
   - زر إعادة إرسال الرمز مع عداد تنازلي 60 ثانية (مرتبط بـ `POST /api/v1/auth/staff/resend-otp`).
4. **حقول كلمة المرور الجديدة**:
   - **كلمة المرور الجديدة**: مع زر إظهار/إخفاء ومؤشرات القوة (8 خانات، حروف، أرقام، رموز).
   - **تأكيد كلمة المرور**: مع زر إظهار/إخفاء والتحقق من التطابق.
5. **زر التأكيد والحفظ**:
   - زر **"تحديث كلمة المرور"** / *"Reset Password"*.

---

## 🔌 تكامل الباك إند (API Integration)

- **الرابط**: `POST /api/v1/auth/staff/reset-password`
- **التوثيق (Auth)**: مفتوح (`Anonymous`)
- **جسم الطلب (Request Body)**:
  ```json
  {
    "phone": "+966501234567",
    "role": "Driver", // أو "DeliveryManager"
    "otpCode": "123456",
    "newPassword": "NewDriver@2026!",
    "confirmPassword": "NewDriver@2026!"
  }
  ```

### استجابة النجاح (200 OK):
```json
{
  "success": true,
  "message": "تمت إعادة تعيين كلمة المرور بنجاح. يمكنك الآن تسجيل الدخول بكلمة المرور الجديدة."
}
```

### الأخطاء المحتملة:
- **400 Bad Request** (`auth.otp_invalid`): الرمز غير صحيح أو منتهي الصلاحية.
- **400 Bad Request** (`validation.password_mismatch`): كلمتا المرور غير متطابقتين.

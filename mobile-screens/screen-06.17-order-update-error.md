# Screen 06.17: خطأ في تحديث الطلبات (Order Update & Sync Error)

## ⚡ سلوك الواجهة (User Flow)
* **زر `[ إعادة المحاولة ]`:** يُعيد إرسال طلب المزامنة إلى الخادم.
* **زر `[ العمل بدون اتصال ]`:** يسمح للسائق بمتابعة فحص الصناديق محلياً مع تخزين البيانات في قاعدة البيانات المحلية (Local Storage) لمزامنتها لاحقاً فور استقرار الشبكة.

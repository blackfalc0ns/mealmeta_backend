# 08.02 - طلب إعادة إسناد الطلب لسائق آخر (Request Reassignment)

## 📌 نظرة عامة (Overview)
* **رقم الشاشة وتسميتها:** `08.02 - طلب إعادة إسناد الطلب لسائق آخر (Request Reassignment)`
* **الهدف التشغيلي:** شاشة تتيح للسائق المتعثر طلب تحويل الطلب لسائق بديل لإكمال التوصيل دون تأخير العميل.
* **المستخدم المستهدف:** السائق الميداني (Driver).
* **الحالة:** عقد مُثبّت ومطابق للتنفيذ (منع تكرار الطلب النشط شاملًا للطلبات المتزامنة).

---

## 🔑 دلالة المعرّفات (Identifier Semantics)
* `boxId` في المسار = **`TripStop.Id` بصيغة UUID** (حقل `BoxId` من خريطة/قائمة الطلبات) — ليس رقم البوكس الظاهر `#BX-####` وليس `DailyOrderId`.
* رقم البوكس في الاستجابة (`boxCode`) هو `OrderCode` للعرض فقط.

## 🔌 إرسال طلب إعادة الإسناد
```http
POST /api/v1/driver/orders/{boxId}/request-reassignment HTTP/1.1
Authorization: Bearer <driver_token>
Content-Type: application/json

{
  "reason": "VehicleBreakdown",
  "notes": "المركبة متوقفة أمام مجمع الأفنيوز، البوكس جاهز للتسليم لأي سائق قريب",
  "latitude": 29.3000,
  "longitude": 47.9300
}
```

### الحقول
| الحقل | مطلوب/اختياري | الحد | القواعد |
| --- | --- | --- | --- |
| `reason` | **مطلوب** | — | **قيمة ثابتة** من الجدول أدناه (تُقبل بأي حالة أحرف وتُحفظ بالشكل القياسي). النص الحر غير مقبول — التفاصيل تُكتب في `notes`. |
| `notes` | اختياري | **250 حرفًا** (بعد إزالة الفراط) | مطابق لعدّاد التصميم. |
| `latitude` + `longitude` | اختياري (زوج) | WGS-84: العرض ‎±90، الطول ‎±180 | **يُرسل الاثنان معًا أو يُحذفان معًا**؛ إرسال أحدهما فقط → 400. عند الإرسال يُتحقق من النطاق ويُحفظ الموقع مع الطلب. |

### القيم المسموحة لـ `reason` (قائمة التصميم الثابتة)
| القيمة الآلية (machine value) | التسمية العربية |
| --- | --- |
| `VehicleBreakdown` | عطل بالمركبة |
| `TrafficAccident` | حادث سير مروري |
| `MedicalOrPersonalEmergency` | ظرف صحي أو طارئ شخصي |
| `DeviceFailure` | نفاد بطارية الهاتف أو عطل في التطبيق |
| `OtherOperationalReason` | سبب تشغيلي آخر |

> ⚠️ تغيير عقد: النسخ السابقة كانت تقبل `reason` كنص حر. القيم أعلاه إلزامية الآن.

## ✅ الاستجابة الناجحة
```http
HTTP/1.1 200 OK
```

```json
{
  "requestId": "f4444444-4444-4444-4444-444444444444",
  "boxId": "c2222222-2222-2222-2222-222222222222",
  "boxCode": "#BX-1256",
  "status": "ReassignmentRequested",
  "message": "تم إرسال طلب إعادة الإسناد للبوكس #BX-1256 بنجاح. سيتم إشعارك فور قبول الطلب من سائق آخر.",
  "requestedAtUtc": "2026-10-07T08:45:00Z"
}
```

`requestId` هو معرّف سجل الدعم المحفوظ فعليًا (Complaint بتصنيف `DriverReassignmentRequested`) — نفس المعرّف الذي يعالجه مسؤول التوصيل في شاشة تعيين سائق بديل (04.13).

## 🔐 شروط القبول
* سجل التوصيل موجود والمتصل سائق **مملوك لإسناد نشط (Active)** على رحلته — البوكس ليس ضمن توصيلاتك النشطة → 403.
* حالة البوكس يجب أن تكون **`PickedUp`** فقط (السائق يحمل الصندوق): أي حالة أخرى → 409 `driver.reassignment.stop_state_not_allowed`.
* **منع التكرار:** لا يمكن وجود أكثر من طلب إعادة إسناد نشط لنفس البوكس. الطلب "نشط" حتى يعالجه مسؤول التوصيل (الحالتان `Submitted` أو `UnderReview`)؛ الطلبات `Resolved/Rejected/Closed` لا تمنع طلبًا جديدًا. الحماية مطبقة على مستوى قاعدة البيانات (فهرس جزئي فريد) فتشمل الطلبات المتزامنة: الناجح الأول فقط يُحفظ، والباقي → 409.
* **إعادة المحاولة:** تكرار إرسال نفس الطلب (مثلًا بعد انقطاع شبكة) يعيد 409 `driver.reassignment.request_already_active` — ليس نجاحًا صامتًا ولا 403؛ تحقق التكرار يسبق تحقق الملكية لهذا الغرض.
* **أثر العملية على إسنادات الرحلة:** عند القبول تُعاد محطة البوكس إلى `Pending` وتُعلَّم إسنادات الرحلة النشطة `Reassigned` — هذا مقصود لأن النموذج إسناد على مستوى الرحلة، ومسار تعيين السائق البديل (04.13) يتولى الرحلة كاملة. لا يتغير أي شيء آخر في إسنادات الطلبات.

## ❌ الأخطاء (ProblemDetails)
الشكل العام: `application/problem+json` مع `title`, `detail` (مترجم حسب `Accept-Language`), `status`, `instance`, و`code` ثابت.

| HTTP | `code` | الحالة |
| --- | --- | --- |
| 400 | `driver.reassignment.reason_invalid` | قيمة `reason` خارج القائمة الثابتة (بما فيها النص الحر). |
| 400 | `driver.reassignment.notes_too_long` | `notes` > 250 حرفًا. |
| 400 | `Orders.CoordinatesPairRequired` | إرسال أحد الإحداثيين دون الآخر. |
| 400 | `Orders.CoordinatesOutOfRange` | إحداثيات خارج نطاق WGS-84. |
| 403 | `driver.reassignment.stop_forbidden` | البوكس ليس ضمن التوصيلات النشطة للسائق. |
| 404 | `order.not_found` | لا يوجد سجل توصيل بهذا `boxId`، أو المتصل موقّع الدخول بلا ملف سائق. |
| 409 | `driver.reassignment.request_already_active` | يوجد طلب إعادة إسناد نشط لنفس البوكس (يشمل الطلبات المتزامنة). |
| 409 | `driver.reassignment.stop_state_not_allowed` | حالة البوكس تسمح فقط بـ `PickedUp` لطلب إعادة الإسناد. |

## 📡 أحداث البث المباشر (SignalR)
عند النجاح يبث الخادم `driver-requested-reassignment` و`driver-issue-updated` إلى `DispatcherHub` (شاشة تعيين سائق بديل 04.13) بحمولة تشمل `requestId` و`boxId` و`reason` و`notes`. فشل البث لا يُبطل الحفظ.

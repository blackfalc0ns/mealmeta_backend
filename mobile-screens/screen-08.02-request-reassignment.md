# 08.02 - طلب إعادة إسناد الطلب لسائق آخر (Request Reassignment)

## 📌 نظرة عامة (Overview)
* **رقم الشاشة وتسميتها:** `08.02 - طلب إعادة إسناد الطلب لسائق آخر (Request Reassignment)`
* **الهدف التشغيلي:** شاشة تتيح للسائق المتعثر طلب تحويل الطلب لسائق بديل قريب منه ميدانياً لإكمال التوصيل دون تأخير العميل، في حالات تعطل المركبة أو الطوارئ الشخصية.
* **المستخدم المستهدف:** السائق الميداني (Driver).

---

## 🎨 عناصر واجهة المستخدم وتجربة الاستخدام (UI / UX Elements)

### 1. الرسم التوضيحي للتبادل (Exchange Illustration)
* رسم متجهي يوضح سائقين مع أسهم تبادل دائرية وصندوق وجبة بنفسجي 👤 🔄 📦 🔄 👤 للإشارة إلى نقل المهمة لسائق بديل.

### 2. العنوان والنص التوجيهي (Headings & Description)
* عنوان بارز: **"طلب إعادة إسناد"**.
* نص تفصيلي:
  > *"هل تواجه مشكلة تمنعك من إكمال التوصيل؟ يمكنك طلب إعادة إسناد الطلب لسائق آخر ليتولى التوصيل نيابة عنك."*

### 3. سبب طلب إعادة الإسناد (Reason Dropdown)
* قائمة منسدلة بالأسباب القياسية:
  * عطل بالمركبة (Vehicle Breakdown).
  * حادث سير مروري (Traffic Accident).
  * ظرف صحي أو طارئ شخصي (Medical/Personal Emergency).
  * نفاد بطارية الهاتف أو عطل في التطبيق (Device Failure).
  * سبب تشغيلي آخر (Other Operational Reason).

### 4. حقل التفاصيل الإضافية (Additional Notes)
* حقل نصي متعدد الأسطر لكتابة تفاصيل إضافية عن موقع التبادل المقترح ومكان تواجد الصندوق.

### 5. أزرار الإجراءات (Action Buttons)
* **الزر الرئيسي:**
  * `[ إرسال الطلب ]` (Submit Reassignment Request).
  * يرسل الطلب فوراً للخادم وينقل السائق إلى شاشة `08.03 - تم إرسال طلب إعادة الإسناد`.
* **رابط الإلغاء:**
  * `إلغاء` للعودة للشاشة السابقة في حال تمكن السائق من مواصلة التوصيل.

---

## 🔌 تكامل الواجهة الخلفية (Backend API Integration)

### إرسال طلب إعادة الإسناد
```http
POST /api/v1/driver/orders/{boxId}/request-reassignment HTTP/1.1
Authorization: Bearer <driver_token>
Content-Type: application/json

{
  "reason": "عطل بالمركبة",
  "notes": "المركبة متوقفة أمام مجمع الأفنيوز، البوكس جاهز للتسليم لأي سائق قريب",
  "latitude": 29.3000,
  "longitude": 47.9300
}
```

**نموذج الاستجابة (Response):**
```json
{
  "requestId": "f4444444-4444-4444-4444-444444444444",
  "boxId": "c2222222-2222-2222-2222-222222222222",
  "boxCode": "BX-1256",
  "status": "ReassignmentRequested",
  "message": "تم إرسال طلب إعادة الإسناد للبوكس BX-1256 بنجاح. سيتم إشعارك فور قبول الطلب من سائق آخر.",
  "requestedAtUtc": "2026-09-23T08:45:00Z"
}
```

### أحداث البث المباشر (SignalR)
* يبث الخادم حدث `driver-requested-reassignment` إلى غرفة مسؤولي التوصيل (`DispatcherHub`) ليظهر في شاشة تعيين سائق بديل للمهمة المتعثرة (الشاشة `04.13 - Assign Replacement Driver`).
